## 🎓 Môn học: CSE391 – Nền Tảng Phát Triển Web

CSE391 là môn học cung cấp các kiến thức nền tảng và thực hành về **công nghệ phát triển Web**, bao gồm:
- HTML, CSS, JavaScript  
- Nguyên lý hoạt động của website  
- Thiết kế giao diện và xây dựng ứng dụng web cơ bản  
- Làm quen với quy trình phát triển web hiện đại  

Thông qua môn học này, mình mong muốn:
- Nắm vững kiến thức cơ bản về lập trình Web  
- Rèn luyện kỹ năng thực hành và tư duy thiết kế  
- Áp dụng kiến thức vào các bài tập, dự án thực tế
